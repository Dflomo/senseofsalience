# senseofsalience

Derek Florimonte's personal site (senseofsalience.com): static pages in `public/`, plus a small Cloudflare Worker (`worker.js`, `src/`) for the gallery upload API (R2 storage). See `SETUP.md` for deploy steps.

## Deploys
Pushing to `main` deploys automatically through Cloudflare Workers Builds (Worker: `wispy-credit-c2b6`).
